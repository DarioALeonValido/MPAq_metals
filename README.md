# MPAq_metals

Spectral properties, momentum dispersion, and broadening of bulk plasmonic excitations in 26 elemental metals.

The database contains:
- reference experimental data (EELS, REELS, Optics)
- numerical first-principle (RPA) data obtained with QuantumEspresso/Yambo codes
- MPA(q) models: effective analytical representations in terms of multipole-Pade approximants in frequency and momentum spaces

See descrimtion on https://arxiv.org/pdf/2510.07261
